# Icons

79 line icons from Lucide (https://lucide.dev), bundled in one file, `icons.json` (name to SVG markup, 24 by 24 grid, drawn with `currentColor` strokes). Licence: ISC, with the MIT licence for the Feather-derived icons; the full text is in `LICENSE.txt` and must stay with the file.

Used through the HTML PDF kit: `d.icon('calendar')` inside any text or layout, `pictogram(icon, on, total)`. An unknown name throws and lists the valid ones. Use an icon only where it names the thing beside it (a person, a date, a place, money); never as ornament.
